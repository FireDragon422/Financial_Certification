金融市場常識與職業道德：113 年版 HTML 模擬測驗
==========================================

【題庫與測驗規格】
- 金融市場常識：504 題
- 職業道德：616 題
- 題庫合計：1,120 題，來源為使用者提供的兩份 113 年版 PDF。
- 正式模擬測驗每次隨機抽：金融市場常識 50 題＋職業道德 50 題。
- 共 100 題四選一，計時 60 分鐘，答對 70 題（70 分）及格。
- 未作答題目也列入錯題；60 分鐘到會自動交卷。

【使用方法】
1. 直接用 Chrome、Edge、Safari 等現代瀏覽器開啟 index.html，即可離線練習。
2. 點選「開始 100 題模擬測驗」開始。
3. 可隨時切換題號、標記題目及交卷。重新整理頁面後可接續作答；計時不中斷。
4. 交卷後可查看分數、正確率、原始題號、正確選項與答錯選項。
5. 「練習紀錄」可查每回分數及按科目展開錯題原始題號。
6. 「錯題整理」可依科目篩選、搜尋、檢查答案並重練。
7. 建議定期用「備份 JSON」下載紀錄，必要時用「匯入備份」還原。
8. 「匯出 CSV」能將每回分數與兩科錯題原始題號輸出為 Excel 可讀取的表格。

【上線為公開網址：GitHub Pages】
1. 新建 GitHub repository，將 index.html 上傳至 repository 根目錄。
2. 打開該 repository 的 Settings → Pages。
3. Build and deployment 選「Deploy from a branch」。
4. Branch 選「main」，Folder 選「/ (root)」，按 Save。
5. 等部署完成後，於 Pages 設定頁使用 GitHub 提供的網址開啟網站。
6. 不需外部題庫、資料庫或其他依賴。

【重要注意事項】
- 每個瀏覽器（與相同網站網址）各自保管紀錄，不會自動同步到其他設備。
- 清除網站資料、改用不同瀏覽器或改用不同網址可能無法讀到舊紀錄。請先匯出 JSON 備份。
- 未上傳至網站時，HTML 仍可離線執行。
- 題目與標準答案沿用使用者提供的 113 年版 PDF，未核對最新法規與答案異動。
- PDF 只有標準答案，因此檢討頁展示正確選項，不會提供自行編造的文字詳解。
