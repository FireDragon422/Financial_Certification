系統包含以下功能： - 正式模擬測驗：每回隨機 100 題、60 分鐘倒數、70 分及格。 - 自動保存進度：重新整理後可繼續作答，倒數時間不中斷。 - 歷次成績紀錄：記錄日期、分數、正確率及兩科錯題原始題號。 - 錯題整理與重練：查看原題、正確答案，統計同一題答錯次數。 - 資料備份：支援 CSV 匯出與 JSON 備份、還原。 已測試隨機抽題比例、交卷計分、滿分判定、歷史紀錄與匯出功能。  使用方式： 下載 HTML 後直接用 Chrome 或 Edge 開啟即可。若要變成真正有網址的線上練習網站。  提醒：成績目前儲存在使用者自己的瀏覽器，不會跨裝置自動同步；建議定期備份 JSON。
